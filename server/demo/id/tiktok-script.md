# Skrip TikTok: Peluncuran Kopi Susu Gula Aren

Durasi: 25 detik. Format vertikal 9:16. (Contoh hasil mode demo AI Office.)

## Hook (0-3 detik)
Teks di layar: "Kopi susu ini bikin kamu telat bangun tidur... tapi nggak telat ngantor."
Visual: close-up es batu jatuh ke gelas, gula aren cair mengalir pelan.

## Isi (3-20 detik)
1. Tuang espresso ke susu dingin, tampilkan gradasi warna.
2. Narasi: "Gula aren asli, susu segar, espresso kuat. Tanpa sirup pabrikan."
3. Potongan cepat: barista mengaduk, gelas diangkat ke kamera, tetes embun di gelas.

## Penutup / ajakan (20-25 detik)
Teks di layar: "Hari ini harga peluncuran. Pesan lewat link di bio."
Narasi: "Cobain sekarang, rasain bedanya."

## Catatan produksi
- Musik: instrumental akustik ceria, 100-110 BPM.
- Pencahayaan natural dari samping supaya embun gelas terlihat.
- Subtitle besar di tengah-bawah layar, hindari area tombol TikTok di kanan.
